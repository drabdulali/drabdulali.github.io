Forest Plot for OR / HR
ggplot2 coefficient plot with log x-axis, hypothesis colour coding, and model facets
▼

Input

Fitted glmer / coxme model objects. broom.mixed::tidy() extracts coefficients, SE, and 95% CI on the log scale.

Output

Forest plot with log x-axis. Points = OR or HR. Horizontal bars = 95% CI. Vertical reference line at 1. Faceted by model type.

Why

Standard evidence-synthesis format. Reviewers expect forest plots. Log x-axis keeps CI bars symmetric. Colour by hypothesis reveals predictor clusters visually.

broom.mixed ggplot2 dplyr forcats
Step 1 — Extract coefficients into a tidy data frame
library(broom.mixed)
library(dplyr)

# --- Persistence model (glmer, logistic) ---
tidy_persist <- broom.mixed::tidy(
  model_persist,
  effects    = "fixed",
  conf.int   = TRUE,
  conf.level = 0.95,
  exponentiate = TRUE   # converts log-OR -> OR automatically
) |>
  filter(term != "(Intercept)") |>
  mutate(
    model = "Persistence (OR)",
    # Map terms to hypothesis labels H1-H5
    hypothesis = case_when(
      term %in% c("livestock_density_z", "herd_size_z")          ~ "H1: Ecological",
      term %in% c("tree_cover_z", "climate_pc1_z")               ~ "H2: Environmental",
      term %in% c("wildlife_prox_z", "forest_edge_z")            ~ "H3: Wildlife Interface",
      term %in% c("road_density_z", "market_access_z")           ~ "H4: Infrastructure",
      term %in% c("vaccination_cov_z", "gdp_pc_z", "vet_cap_z") ~ "H5: Institutional",
      TRUE ~ "Other"
    )
  )

# --- Reemergence model (coxme / coxph frailty) ---
tidy_reemerg <- broom.mixed::tidy(
  model_reemerg,
  effects      = "fixed",
  conf.int     = TRUE,
  conf.level   = 0.95,
  exponentiate = TRUE   # log-HR -> HR
) |>
  filter(term != "(Intercept)") |>
  mutate(
    model = "Reemergence (HR)",
    hypothesis = case_when(
      term %in% c("livestock_density_z", "herd_size_z")          ~ "H1: Ecological",
      term %in% c("tree_cover_z", "climate_pc1_z")               ~ "H2: Environmental",
      term %in% c("wildlife_prox_z", "forest_edge_z")            ~ "H3: Wildlife Interface",

Why facet by model type? Persistence (OR) and reemergence (HR) have different reference scales and clinical interpretations. Faceting avoids conflating two different estimands on a single axis while still enabling visual comparison of direction and relative magnitude across predictors.
Pitfall: exponentiate = FALSE then plotting raw coefficients If you omit exponentiate = TRUE in tidy(), the x-axis shows log-ORs and your reference line must be at 0, not 1. The log scale on the x-axis (scale_x_log10) only makes sense after exponentiating. Always check which scale you are on before building the plot.

dwplot vs. custom ggplot2 dwplot() handles the fiddly details: reordering by magnitude, offsetting dots vertically when multiple models share a predictor, and returning a fully customisable ggplot object. Use it for quick drafts. Switch to the custom ggplot2 approach (Card F1) for publication figures that need facets or log x-axis.
Pitfall: mixing exponentiated and log-scale estimates dwplot() is designed for log-scale coefficients (reference line at 0). If you pass exponentiated ORs, the reference line must shift to 1 and the spacing looks compressed near zero. Phase 2 — Discrimination and Calibration
R3
ROC Curve and AUC
pROC + ggroc() with confidence band, AUC annotation, and conditional predictions
▼

Input

Binary outcome vector and conditional predicted probabilities from predict(model, type="response"). Must use conditional (not marginal) predictions for mixed models.

Output

ROC curve plot with AUC text annotation, diagonal reference line (no discrimination), and 95% confidence band via bootstrapped sensitivity estimates.

Why pROC

Handles censoring, CI computation via bootstrap or DeLong, produces ggplot-compatible output with ggroc(), and enables statistical comparison of two AUCs.

pROC ggplot2
Critical: always use conditional predictions for mixed model AUC predict(model, type="response") in lme4/glmer gives conditional predictions — incorporating the estimated random effects. Marginal predictions (averaging over random effects) underestimate discrimination and produce an artificially lower AUC. Conditional predictions are the correct metric for within-sample model performance. For out-of-sample AUC use held-out data with newdata.
Step 1 — Obtain conditional predictions and build ROC object
library(pROC)

# Conditional predicted probabilities (incorporates random effects)
pred_prob <- predict(model_persist, type = "response")

# Build ROC object
roc_obj <- pROC::roc(
  response  = dat$persistence,   # binary 0/1 outcome
  predictor = pred_prob,
  direction = "<",               # higher prediction = higher risk
  quiet     = TRUE
)

# Point estimate
cat(sprintf("AUC = %.3f (95%% CI: %.3f-%.3f)\n",
            pROC::auc(roc_obj),
            pROC::ci.auc(roc_obj)[1],
            pROC::ci.auc(roc_obj)[3]))

# Bootstrap confidence band on sensitivity at fixed specificities
ci_band <- pROC::ci.se(
  roc_obj,
  specificities = seq(0, 1, by = 0.02),
  boot.n        = 1000,
  progress      = "none"
)
ci_df <- as.data.frame(ci_band)
ci_df$specificity <- as.numeric(rownames(ci_df))
names(ci_df) <- c("sens_lo", "sens_mid", "sens_hi", "specificity")
Step 2 — Build ROC plot with ggroc() and ggplot2 layers

                     auc_val,
                     round(auc_ci[1], 3),
                     round(auc_ci[3], 3))

Interpreting AUC for mixed models AUC > 0.70 indicates acceptable discrimination; > 0.80 is excellent. For mixed models the conditional AUC reflects how well the model distinguishes persistence within the observed group structure — a higher bar than marginal AUC. Report which type you used. For cross-validated AUC use predictions generated on held-out folds only.
C4
Calibration Plot
Decile grouping, mean predicted vs. mean observed, Hosmer-Lemeshow annotation
▼

Input

Conditional predicted probabilities + binary outcome. Grouped into 10 equal-frequency deciles of predicted probability.

Output

Scatter plot: mean predicted probability (x) vs. mean observed proportion (y) per decile. Reference diagonal = perfect calibration. Hosmer-Lemeshow p-value annotated.

Why

AUC measures discrimination (ranking), not calibration (accuracy of probabilities). A model can have AUC 0.85 but be severely miscalibrated. Both diagnostics are required.

ggplot2 dplyr ResourceSelection
Step 1 — Compute decile calibration data frame
library(dplyr)

# Attach predictions to data
calib_df <- dat |>
  mutate(
    pred_prob = predict(model_persist, type = "response"),
    decile    = ntile(pred_prob, 10)   # 10 equal-frequency bins
  ) |>
  group_by(decile) |>
  summarise(
    mean_pred = mean(pred_prob),
    mean_obs  = mean(persistence),
    n         = n(),
    .groups   = "drop"
  )

# Hosmer-Lemeshow goodness-of-fit test
library(ResourceSelection)
hl_test <- hoslem.test(
  x = dat$persistence,
  y = predict(model_persist, type = "response"),
  g = 10
)
hl_pval <- sprintf("Hosmer-Lemeshow p = %.3f", hl_test$p.value)
Step 2 — Build calibration plot with ggplot2
library(ggplot2)

calib_plot <- ggplot(calib_df, aes(x = mean_pred, y = mean_obs)) +

  # Perfect calibration line
  geom_abline(slope = 1, intercept = 0,
              linetype = "dashed", colour = "grey50", linewidth = 0.7) +

  # Calibration ribbon: acceptable zone (+-0.1)
  geom_ribbon(
    data = data.frame(x = c(0,1)),
    aes(x = x, ymin = pmax(0, x - 0.1), ymax = pmin(1, x + 0.1)),
    fill = "#bbf7d0", alpha = 0.3, inherit.aes = FALSE
  ) +

  # Calibration line connecting decile points
  geom_line(colour = "#1976d2", linewidth = 0.8, alpha = 0.7) +

  # Decile points; size proportional to n
  geom_point(aes(size = n), colour = "#1976d2",
             fill = "#eff6ff", shape = 21, stroke = 1.2) +

  # Point labels
  geom_text(aes(label = decile), colour = "white",
            size = 2.5, fontface = "bold") +

  # HL p-value annotation
  annotate("label",
    x = 0.75, y = 0.1,
    label    = hl_pval,
    size     = 3.2,
    colour   = ifelse(hl_test$p.value > 0.05, "#2e7d32", "#c62828"),
    fill     = ifelse(hl_test$p.value > 0.05, "#f0faf0", "#fde0dc"),
    label.size = 0.35
  ) +

  scale_size_continuous(range = c(4, 10), guide = "none") +

  scale_x_continuous(name = "Mean Predicted Probability",

  scale_y_continuous(name = "Mean Observed Proportion",
                     limits = c(0, 1), expand = c(0.02, 0.02)) +

  labs(
    title    = "Calibration Plot — TAD Persistence Model",
    subtitle = "10 equal-frequency deciles of predicted probability\nGreen band = ±0.10 acceptable calibration zone",
    caption  = "Romania ASF 2018-2024 | ResourceSelection::hoslem.test()"
  ) +

  theme_classic(base_size = 11) +
  theme(
    plot.title    = element_text(face = "bold"),
    plot.subtitle = element_text(colour = "grey50", size = 9),

  )

Alternative: CalibrationCurves package CalibrationCurves::val.prob.ci.2() produces a calibration plot with LOESS smoothed curve, E50/E90 calibration error statistics, and integrated calibration index (ICI) in one call. Useful for supplementary material. The manual ggplot2 approach above gives more publication-quality control.
Pitfall: Hosmer-Lemeshow p-value in large samples With n > 1,000 the HL test has very high power and will reject H0 (good calibration) even for clinically trivial deviations. Supplement with the E-statistic (mean absolute calibration error per decile) and visual inspection. A significant HL p-value does not automatically mean the model is poorly calibrated — inspect the plot first.

Reading the KM plot The y-axis is the estimated probability of remaining reemergence-free. A step downward = one or more events. Tick marks = censored observations (follow-up ended without reemergence). The log-rank p-value tests whether all groups have the same survival function (H0). The Cox model (Card CH6) gives adjusted HRs after accounting for covariates.
Pitfall: interpreting KM curves as adjusted estimates KM curves are unadjusted (marginal) estimates. They show the raw difference between groups without controlling for confounders. Never conclude causality from a KM curve alone. The purpose is visual exploration and hypothesis generation — the Cox model provides the adjusted analysis.
CH6
Cumulative Hazard and Smooth Hazard Plots
Nelson-Aalen estimator, muhaz smoothed hazard, and Cox predicted survival by risk group
▼

Input

Fitted Cox PH frailty model. basehaz() extracts cumulative baseline hazard. Risk groups defined by tertile of linear predictor.

Output

Three plots: (1) Nelson-Aalen cumulative hazard, (2) kernel-smoothed hazard rate over time, (3) predicted survival curves for high/medium/low risk groups.

Why

Cumulative hazard is easier to estimate than the hazard function. Smoothed hazard reveals temporal patterns (e.g. seasonal peaks). Risk-group survival curves show clinical significance of the model.

DHARMa and Random Effects Caterpillar Plots
Simulation-based residuals, QQ plots, and ordered dot-plot of BLUPs with CI bars
▼

Input

Fitted glmer/coxme model. DHARMa simulates from the fitted model to compute scaled residuals. Random effects extracted via ranef() or broom.mixed::tidy(effects="ran_vals").

Output

DHARMa: uniform QQ plot + residual vs. fitted plot. Caterpillar: ordered random effect estimates with 95% CI bars, faceted by grouping level.

Why DHARMa

Standard Pearson/deviance residuals are invalid for GLMMs. DHARMa uses simulation to produce valid scaled residuals that follow U(0,1) under correct model specification — applicable to logistic, Poisson, and Cox models.

DHARMa lattice broom.mixed ggplot2

Reading the caterpillar plot Each point is a Best Linear Unbiased Predictor (BLUP) — the estimated deviation of that group from the overall mean on the log-odds scale. Points with CI bars that exclude zero (shown in red) represent groups that systematically deviate from the mean. A wide spread of BLUPs indicates large between-group variation — the random effect is doing important work. A very tight cluster near zero suggests the random effect is not needed (check ICC).
Pitfall: DHARMa refit = TRUE for boundary estimates If the model is near a boundary (variance estimate = 0 for a random effect), DHARMa with refit = FALSE may show false patterns. In these cases use refit = TRUE (slower — refits model n times) for valid residuals. Also note: DHARMa works well for glmer and glmmTMB but requires special handling for coxme (use cox.zph and Schoenfeld residuals for Cox models instead).
Pitfall: plotting all admin-2 BLUPs when n is large With 537 communes, the y-axis becomes unreadable if you plot every unit. Options: (1) plot only the top/bottom 30 by estimate, (2) use a histogram of BLUPs instead, (3) bin by quantile. The filter(rank(abs(estimate)) > (n()-30)) idiom selects the 30 most extreme BLUPs for inspection.
