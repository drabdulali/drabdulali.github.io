Life Table Analyzer

Calculate survivorship, fecundity schedules, and key demographic parameters from life table data.

Life Table Data

Age (x) Survivors (nx) lx (survivorship) dx (deaths) qx (mortality rate) mx (fecundity) lx*mx x*lx*mx

Demographic Parameters

--
Net Reproductive Rate (R0)
R0 = sum(lx * mx)
--
Generation Time (T)
T = sum(x*lx*mx) / R0
--
Intrinsic Rate (r)
r = ln(R0) / T
--
Finite Rate (lambda)
lambda = e^r
--
Life Expectancy (e0)
e0 = sum(Lx) / l0
--
Population Status
R0 > 1 = growing
