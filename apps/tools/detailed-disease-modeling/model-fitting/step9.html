9 Model Validation

Model Validation

Test whether the model predicts correctly — using five complementary validation methods, not just a train/test split.

← Overview 1–2 Data & model 3 Preprocessing 4 Likelihood 5 Grid search 6 MLE 7 GOF 8 CI 9 Validation 10–11 LHS & PRCC

Five validation methods

MethodQuestion answeredBest for
Holdout (80/20)Can the model predict the last 20% of the epidemic?Temporal prediction ability
\(k\)-fold cross validationIs fit consistent across different sub-periods?Stability assessment
Leave-one-out (LOO)Does removing one day destabilise estimates?Very short outbreaks
Simulation recoveryCan the method recover true \(\beta\) and \(\gamma\) from simulated data?Method correctness
Prospective validationDoes the model fitted on outbreak 1 predict outbreak 2?Generalisability

V27 — Holdout validation (80/20 temporal split)

Prediction interval coverage
\[\text{Coverage} = \frac{1}{n_{\mathrm{test}}}\sum_{t \in \text{test}}\mathbf{1}\!\left[y_t \in \hat{C}_{95}(t)\right] \approx 0.95\]
V27 — Train (blue), predict (red dashed + band), observed holdout (green dots)
Model trained on days 1–40, predicts days 41–50. Green dots (holdout observations) fall mostly inside the shaded 95% PI band, confirming good predictive performance. PI coverage = 90% (9/10 points inside).

\(k\)-fold cross validation

5-fold validation — each colour = one fold held out
Each fold produces a fitted curve. Consistent overlap confirms stable estimates across different time periods.

V28 — Simulation recovery (100 runs)

Run 100 simulated outbreaks with known \(\beta_{\text{true}} = 0.32\). For each, fit the full pipeline and record \(\hat\beta\). Plot \(\hat\beta\) vs \(\beta_{\text{true}}\) — if points cluster on the diagonal, the method is unbiased.

V28 — Simulation recovery: \(\hat\beta\) vs \(\beta_{\text{true}}\) (100 synthetic outbreaks)
Points scattered symmetrically around the diagonal — method is unbiased. Average \(\hat\beta = 0.321 \pm 0.024\). 95% of 95% CIs contained the true value (nominal coverage achieved).

Prospective validation

Prospective — model fitted on outbreak 1 predicts outbreak 2
Blue dashed = prediction from outbreak-1 parameters. Red dots = outbreak 2 observations. Agreement (despite different outbreak) supports generalisability of \(\hat\beta\) and \(\hat\gamma\).
