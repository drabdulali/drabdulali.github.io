5 Grid Search

Grid Search — Initial Parameter Estimation

Evaluate the log-likelihood at every point on a \(50\times 50\) grid over \((\beta,\gamma)\) space. Each dot requires one full ODE run.

← Overview 1–2 Data & model 3 Preprocessing 4 Likelihood 5 Grid search 6 MLE 7 Goodness of fit 8 Confidence intervals 9 Validation 10–11 LHS & sensitivity

How each dot in the heatmap is scored

This is the key conceptual link in the pipeline. Each coloured dot in the heatmap is not just a number — it is the result of running the full SIR ODE, comparing the predicted curve to observed data, and scoring that comparison with the NegBin likelihood from Step 4.

Score for grid cell \((\beta_i, \gamma_j)\)
\[\text{score}_{ij} = \sum_{t=1}^{T}\log P_{\mathrm{NB}}\!\left(y_t \,\Big|\, \hat{I}_t(\beta_i,\gamma_j),\,k\right)\]
Reading this equation:
  • \(y_t\) = the observed number of new cases on day \(t\)
  • \(\hat{I}_t(\beta_i,\gamma_j)\) = the ODE-predicted infected count on day \(t\) using this grid cell's parameters
  • \(P_{\mathrm{NB}}\) = the Negative Binomial probability of observing \(y_t\) given that prediction
  • We sum the log-probabilities over all \(T\) days — the higher this sum, the better the parameter pair fits the data

The ODE runs 2,500 times (50×50 grid cells), once per cell. This is computationally feasible in minutes for SIR models but would be impractical for more complex models — which is why Step 6 uses an efficient optimizer instead of relying on the grid alone.

The three stages for each dot

Stage 1

Run ODE with \((\beta_i,\gamma_j)\) → get predicted \(\hat{I}(t)\) for all \(T\) days

Stage 2

Compare \(\hat{I}(t)\) to observed \(y_t\). Compute \(\log P_{\mathrm{NB}}(y_t|\hat{I}_t,k)\) for each day

Stage 3

Sum all log-probabilities → total score → colour of that dot in the heatmap

Why not just use the grid?

The grid has resolution 1/50 in each dimension. The true optimum may lie between grid points. Step 6 uses Nelder-Mead to find the exact optimum to within \(10^{-6}\) tolerance, using the grid peak as a starting point.

What Step 5 gives the rest of the pipeline

A warm start: the grid peak \((\beta=0.30,\,\gamma=0.10)\) is passed directly to the Nelder-Mead optimizer in Step 6 as its initial simplex centre. Starting near the optimum means fewer function evaluations and avoids convergence to remote local minima.
