The core model — SIR equations

ODE system

\[\frac{dS}{dt} = -\frac{\beta\, S\, I}{N}\] \[\frac{dI}{dt} = \frac{\beta\, S\, I}{N} - \gamma I\] \[\frac{dR}{dt} = \gamma I\]

The constraint \(S + I + R = N\) holds at all times. Frequency-dependent transmission is used because contact rates do not scale with population size in a finite farm network.

Key quantities

\(\beta\)Transmission rateday\(^{-1}\)

Epidemic grows when \(\mathcal{R}_0 > 1\) and fades when \(\mathcal{R}_0 \leq 1\).

What you will learn

Growth rate & crude \(\mathcal{R}_0\)

Estimate \(r\) from the log-linear slope of early cases and compute \(\mathcal{R}_0 \approx r/\gamma + 1\) with an interactive \(\gamma\) slider.

Likelihood & distribution choice

Why NegBin with dispersion \(k\) beats Poisson for overdispersed outbreak data. Formal AIC / BIC model selection.

MLE & Nelder-Mead

Minimize \(-\ell(\beta,\gamma)\) with the simplex algorithm. 50 random restarts prevent local minima traps.

Profile likelihood CI

CIs for \(\hat\beta\), \(\hat\gamma\), \(\hat{k}\), \(\hat{\mathcal{R}}_0\) via the cutoff \(\ell_{\max} - \tfrac{1}{2}\chi^2_{1,\,0.95}\).

Goodness of fit

Pearson residuals \(e_t = (y_t - \hat\mu_t)/\sqrt{\hat\mu_t(1+\hat\mu_t/k)}\), Q-Q plots, ACF. Good vs bad side-by-side.

LHS & PRCC

Latin Hypercube Sampling with \(n \geq \tfrac{4}{3}k^2\). PRCC ranks how strongly each input parameter drives model output.

MCMC & posteriors

Accept \(\theta^*\) with probability \(\alpha = \min(1,\, \pi(\theta^*\mid y)/\pi(\theta_t\mid y))\). Check convergence via \(\hat{R} < 1.1\).

Model validation

Five methods: holdout 80/20, \(k\)-fold CV, LOO, simulation recovery (\(\hat\beta\) vs \(\beta_{\text{true}}\)), and prospective validation.

Profile likelihood CIs for all parameters: \(\hat\beta\), \(\hat\gamma\), \(\hat{k}\), and \(\hat{\mathcal{R}}_0\). Four CI methods compared. Wide CI means insufficient data — never arbitrarily refix a parameter.

Profile likelihood 95% CI
\[\mathcal{C}_{95} = \{\theta : \ell_p(\theta) \geq \ell_{\max} - \tfrac{1}{2}\chi^2_{1,\,0.95}\}\]

Case study — farm outbreak dataset

Simulated farm outbreak — true parameters known

Throughout all 11 steps the same dataset is used: 200 farms of varying herd sizes, with disease spreading via a distance-dependent transmission kernel. The true parameters are \(\beta = 0.32\;\text{day}^{-1}\) and \(\gamma = 0.11\;\text{day}^{-1}\), giving a true \(\mathcal{R}_0 = \beta/\gamma = 2.91\). Observed case counts include a realistic observation layer — reporting delays and partial detection. The goal of the full pipeline is to recover \(\hat\beta \approx 0.32\) and \(\hat\gamma \approx 0.11\) from the noisy observed data alone, and to quantify uncertainty in \(\hat{\mathcal{R}}_0\).
