Range Bagging Demo

Simulating ecological niche modeling with presence-only data using bootstrap aggregation

📐 Mathematical Model & Notation

Range Bagging Prediction:

$$\hat{P}(\mathbf{x}) = \frac{1}{B} \sum_{b=1}^{B} \mathbb{1}[\mathbf{x} \in \text{Hull}(S_b)]$$

\(\hat{P}(\mathbf{x})\)
Predicted probability that location x is suitable habitat
\(\mathbf{x} = (x_1, x_2)\)
Location in environmental space (e.g., temperature, rainfall)
\(B = 20\)
Number of bootstrap iterations
\(S_b\)
Bootstrap sample b (70% of original points)
\(\text{Hull}(S_b)\)
Convex hull around bootstrap sample b
\(\mathbb{1}[\cdot]\)
Indicator function: 1 if condition true, 0 otherwise
\(D = \{p_1, p_2, ..., p_n\}\)
Original occurrence dataset with n = 50 points
\(E_{\text{true}}\)
True ecological niche (unknown in practice, shown in red)

Bootstrap Sampling Process:

$$S_b \sim \text{Sample}(D, \text{size} = 0.7n, \text{replace} = \text{FALSE})$$

Each bootstrap sample randomly selects 70% of the original occurrence points without replacement

Convex Hull Definition:

$$\text{Hull}(S) = \left\{ \mathbf{x} \in \mathbb{R}^2 : \mathbf{x} = \sum_{i=1}^{k} \lambda_i p_i, \; \sum_{i=1}^{k} \lambda_i = 1, \; \lambda_i \geq 0 \right\}$$

The smallest convex polygon containing all points in sample S

How it Works:

  1. 1. Blue dots (D): Species occurrence records (n=50)
  2. 2. Red ellipse (Etrue): True niche (unknown in reality)
  3. 3. Bootstrap (Sb): Sample 70% of points randomly
  4. 4. Convex hull (Hull(Sb)): Draw boundary around sample
  5. 5. Vote (B times): Repeat 20 iterations, average predictions
  6. 6. Heatmap (Ŝ(x)): Areas with high votes = predicted niche

Controls:

Iteration: b = 0 / B = 20

Key Insight:

Even though each bootstrap sample creates an imperfect boundary (orange), averaging many samples (blue heatmap) provides a robust estimate of the true niche (red dashed ellipse). The prediction \(\hat{P}(\mathbf{x})\) represents the fraction of bootstrap hulls that contain location x. Areas voted "inside" by many hulls (high \(\hat{P}(\mathbf{x})\) values) are confidently predicted as suitable habitat. This demonstrates how ensemble methods can overcome the limitations of individual models and reduce overfitting in species distribution modeling.
