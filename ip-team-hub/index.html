Editing this dashboard
How to add or change a button

Open the file in any text editor and find the DATA list near the top. Copy one { … } line and set label (button text), url (the link — for a specific Google Sheet tab, copy the tab's URL ending in #gid=…), and optionally desc and icon. Save. Copy a whole group block to add a new color-coded section. Leaving url:"#" keeps a button as a dashed placeholder.
